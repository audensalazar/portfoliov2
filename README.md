# Auden Portfolio — Corrected v10

This folder is ready for GitHub Pages. The Admissions project cover is the exact uploaded `AdmissionsMarketing(1).png`, stored under `assets/images/admissions-marketing-original-v10.png`.

## Update GitHub

1. Unzip and upload the **contents** of this folder into the root of your Portfolio repository (same folder where `index.html` lives).
2. Replace the existing HTML, CSS, JavaScript, and JSON files.
3. Upload the complete `assets/images/` folder, including the new Admissions image.
4. Commit changes, then wait for the GitHub Pages deployment to finish.
5. Check `https://audensalazar.github.io/Portfolio/assets/images/admissions-marketing-original-v10.png` directly.
6. Refresh your webpage with a hard reload if cached content remains.

You can delete the old `assets/images/admissions-think-prep-v9.png` and `assets/images/AdmissionsMarketing.png` files after confirming the update.

The site still uses `projects.json` to manage project details and image paths. The role tags and hover interactions from v9 are preserved.
