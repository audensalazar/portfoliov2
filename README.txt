PORTFOLIO UPDATE

1. Download and extract this ZIP.
2. Download/clone the portfoliov2 GitHub repository to your computer.
3. From Terminal, run:
   python3 apply_portfolio_updates.py /path/to/portfoliov2
   (Change /path/to/portfoliov2 to the actual folder.)
4. Preview changes locally, then commit and push the updated files and new images to GitHub.
